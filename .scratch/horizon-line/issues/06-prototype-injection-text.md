Type: prototype
Status: open
Blocked by: 03

## Question

Andre's draft, verbatim from the kickoff:

> Horizon line: "(the dynamic persisted line will be added here)". Horizon
> line is a goal to be achieved across multiple LLM sessions, not necessarily
> in this one. It should have only high level description. Use command
> (command) to update the horizon line as we go.

Produce 3 concrete variants of the final injected text — full strings, not
descriptions — and get a pick or a hybrid. Things to vary and react to:

- How hard it discourages the model from trying to finish the horizon *this*
  session (the failure mode this whole project exists to prevent).
- Whether the update command is named inline or only mentioned on absence.
- Whether it states who authored the line and when.
- Whether it survives being the 2nd or 3rd injected block (moving-target may
  also be injecting — see ticket 07).

Link the variants as an asset; do not paste the whole set into the map.
